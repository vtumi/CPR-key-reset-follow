# v0.1.6

## 更新

- SDK 与打包工具升级到官方 CPR v3.31.1，固定提交 `06e1d8f0ac33d8633198d837c4f9017ad466f358`
- 移除 CPR 宿主版本上限，保留最低版本 3.29.7
- 插件显示作者设为 `tumi`，同步 Rust 与前端包的作者和版本信息
- 插件标识改为 `tumi.key-reset-follow`，安装包文件名同步使用新标识

## 兼容与升级

- 要求官方 Codex Proxy RS **≥3.29.7**，使用 RPC v5、Management v2、Maintenance v1；无版本上限不代表已经验证所有未来版本
- `tumi.key-reset-follow` 是独立于 `ming321.key-reset-follow` 的新插件，不能通过旧插件的版本切换直接更新。**先停用旧插件，再确认安装新插件**；宿主可能在安装后自动启用，不能让两个插件同时处理同一批密钥
- 私有状态按插件实例隔离；即使继续使用 `follow/state`，旧关联、设置、暂停状态、周期基线和“结果未知”保护也不会自动迁移。需要参考旧记录时保留已停用的旧实例，在新插件中重新建立关联并核对提前重置开关；新关联只建立基线，不补做历史清零
- 周期判定与清零策略不变；本版本不执行跨插件状态迁移，也不修改生产实例
- Linux x86_64 与 ARM64 安装包及对应 SHA-256 文件由标签工作流生成，安装时选择与宿主架构匹配的归档

## 验证

本地验证覆盖格式检查、严格 all-target Clippy、全部 29 项 Rust 测试、release 编译、前端 lint、全部 6 项前端测试与生产构建；清单测试覆盖插件标识、最低宿主、无版本上限、RPC 合同、作者和版本一致性

真实宿主安装、升级和状态保留尚未重新联调；本地检查与 CI 不能替代该验证。本次发布不执行生产部署
