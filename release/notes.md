# v0.1.7

## 更新

- SDK 与打包工具升级到官方 CPR v3.33.0，固定提交 `8c8618aa0f841638262262e3338c115bc075f125`
- 使用 RPC v7，最低宿主版本为 3.33.0，不设置版本上限
- 插件标识仍为 `tumi.key-reset-follow`，作者仍为 `tumi`；周期判定、提前重置开关和结果未知时不重试的保护不变

## 兼容与升级

- 要求官方 Codex Proxy RS **≥3.33.0**，支持 RPC v7、Management v2、Maintenance v1；无版本上限不代表已经验证所有未来版本
- 旧版宿主不能使用本安装包；先升级宿主，再安装与服务器架构匹配的插件包
- 从 v0.1.6 更新保持相同插件标识和私有状态 schema，不需要重新建立关联；升级后仍须核对原有关联、开关、暂停状态和结果未知保护
- 从 `ming321.key-reset-follow` 切换属于独立安装：先停用旧插件，避免两个插件处理同一批密钥；旧实例状态不会自动迁移，新关联只建立基线、不补做历史清零
- Linux x86_64 与 ARM64 安装包及对应 SHA-256 文件由标签工作流生成

## 验证

本地验证覆盖格式检查、严格 all-target Clippy、全部 29 项 Rust 测试、release 与故障代理编译、前端 lint、全部 6 项前端测试、类型检查与生产构建，以及 x86_64 打包与摘要核对

现有前端锁文件存在快照位置错误；按项目规定使用非冻结安装完成依赖准备，锁文件修复不包含在本版本中

真实宿主安装、升级和状态保留尚未重新联调；本地检查与 CI 不能替代该验证。本次发布不执行生产部署
