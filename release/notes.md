# v0.1.9

## 更新

- 新增批量删除：支持当前页全选和跨页选择，确认后仅删除插件关联，不删除宿主密钥或账号
- 批量操作顺序执行，遇到错误立即停止且不自动重试；刷新权威状态后保留尚存选择，搜索条件改变时清空选择
- 默认按关联记录创建时间倒序；新建关联记录创建时间，启用、禁用及设置变更保留该时间
- 旧关联缺少可靠创建时间，保留未知值并稳定排在已知创建时间的记录之后，不推断历史时间
- 排序图标改为宿主同款双三角形；分页栏固定在页面容器底部，不添加分割线
- 无关联及无搜索结果统一显示“暂无关联”；行内删除按钮提示简化为“删除”，单条删除确认文字不变
- 周期判定、提前重置和结果未知时不自动重试的保护保持不变

## 兼容与升级

- SDK 与打包工具继续固定官方 CPR v3.33.0，提交 `8c8618aa0f841638262262e3338c115bc075f125`
- 要求官方 Codex Proxy RS **≥3.33.0**，支持 RPC v7、Management v2、Maintenance v1，不设置宿主版本上限；无上限不代表已验证所有未来版本
- 插件标识为 `tumi.key-reset-follow`，作者为 `tumi`；从 v0.1.8 更新保持相同标识与私有状态 schema，升级后仍须核对原有关联、开关、暂停状态和结果未知保护
- 从 `ming321.key-reset-follow` 切换属于独立安装：先停用旧插件，避免两个插件处理同一批密钥；旧实例状态不会自动迁移，新关联只建立基线、不补做历史清零
- Linux x86_64 与 ARM64 安装包及对应 SHA-256 文件由标签工作流生成
