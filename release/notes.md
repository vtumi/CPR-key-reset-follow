# v0.1.3 — 跟随重置

首次正式版发布，适配官方 Codex Proxy RS v3.29.1 及兼容的 3.x 版本（RPC v4 / Management v2）。

- 跟随 Codex 账号周额度周期更新关联密钥的周预算，正常换周自动清零；首次建立关联只记录基线。
- 支持「提前重置」滑动开关；关闭后遇到提前重置仅更新周期基线，不清零。
- 管理页面精简为「正常 / 异常 / 禁用」三种状态，支持刷新、启停、删除关联。
- 清零意图先持久化，结果未知时停止自动重试，以免重复执行不可逆操作。
- 修复页面状态版本频繁变化导致的操作冲突提示，同时保留写入时的版本校验。
- 提供 Linux x86_64 与 ARM64 安装包及 SHA-256 校验文件。

## 测试与升级说明

已由维护者确认完成实际宿主联调；本次未取得可公开的联调环境、日志或操作记录。GitHub Actions 会验证格式、静态检查、单元测试、前端构建和双架构打包。建议生产安装前备份宿主数据并先在测试环境升级，检查原有关联与开关状态。

适配 CPR v3.29.1 起的 3.x 版本，不支持早于 v3.29.1 的宿主。真实环境中已执行的预算清零无法撤销。
