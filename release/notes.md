# v0.2.2

## 更新

- 修复 CPR v3.37.2 升级后插件主题样式失效：管理页明确声明 `cp` 主题变量前缀，不再依赖新宿主默认的 `z` 前缀
- 开发入口和实际打包的经典脚本 HTML 同步声明前缀，确保安装包获得正确的颜色、表格背景、组件及明暗主题更新
- 保留列表间距、圆角、紧凑行高、批量删除、默认排序及全部重置逻辑

## 兼容与升级

- SDK 与打包工具继续固定官方 CPR v3.33.0，提交 `8c8618aa0f841638262262e3338c115bc075f125`
- 要求官方 Codex Proxy RS **≥3.33.0**，支持 RPC v7、Management v2、Maintenance v1，不设置宿主版本上限；无上限不代表已验证所有未来版本
- 插件标识为 `tumi.key-reset-follow`，作者为 `tumi`；从 v0.2.1 更新保持相同标识与私有状态 schema，升级后仍须核对原有关联、开关、暂停状态和结果未知保护
- 从 `ming321.key-reset-follow` 切换属于独立安装：先停用旧插件，避免两个插件处理同一批密钥；旧实例状态不会自动迁移，新关联只建立基线、不补做历史清零
- Linux x86_64 与 ARM64 安装包及对应 SHA-256 文件由标签工作流生成

## 验证

本地验证覆盖前端 lint、全部 16 项前端测试、类型检查与生产构建，以及版本、清单兼容声明和差异空白检查。

使用固定版本官方主题桥接代码在合成 DOM 中复现缺少前缀的问题，并验证 CPR v3.37.2 的初始主题及反复明暗切换、CPR v3.33.0 的旧桥接兼容；这不是浏览器或真实宿主集成测试。

上一版本 v0.2.1 的双架构 CI 已通过 Rust 格式检查、Clippy、测试、构建及打包；这不替代本次 v0.2.2 标签的独立验证。

本次使用现有安装的前端依赖；现有锁文件问题未在本版本中修复。当前环境没有 Cargo，未重新运行 Rust 格式检查、Clippy、测试、二进制构建与打包；这些检查仍由手动标签工作流执行，须以该次 CI 实际结果为准。

浏览器交互检查与截图受到环境限制，未完成。真实宿主安装、升级和状态保留尚未重新联调；前端检查与 CI 不能替代该验证。本次发布不执行生产部署。
