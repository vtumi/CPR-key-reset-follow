# v0.2.1

## 更新

- 关联列表使用与宿主 API 密钥表格一致的透明单元格边框，记录间保留 6px 空隙，首行顶部保留 6px 空隙
- 记录两端采用宿主主题圆角（默认 8px），交替背景、选中与悬停颜色裁剪到单元格内，不再填满行间空隙
- 移动端按整张记录卡片应用间距和圆角，字段之间不额外增加桌面单元格间距
- 保留紧凑行高、按关联记录 `created_at` 默认倒序，以及搜索、分页、批量删除行为
- 周期判定、提前重置及结果未知时不自动重试的保护保持不变

## 兼容与升级

- SDK 与打包工具继续固定官方 CPR v3.33.0，提交 `8c8618aa0f841638262262e3338c115bc075f125`
- 要求官方 Codex Proxy RS **≥3.33.0**，支持 RPC v7、Management v2、Maintenance v1，不设置宿主版本上限；无上限不代表已验证所有未来版本
- 插件标识为 `tumi.key-reset-follow`，作者为 `tumi`；从 v0.2.0 更新保持相同标识与私有状态 schema，升级后仍须核对原有关联、开关、暂停状态和结果未知保护
- 从 `ming321.key-reset-follow` 切换属于独立安装：先停用旧插件，避免两个插件处理同一批密钥；旧实例状态不会自动迁移，新关联只建立基线、不补做历史清零
- Linux x86_64 与 ARM64 安装包及对应 SHA-256 文件由标签工作流生成
