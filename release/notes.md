# v0.2.0

## 更新

- 关联列表移除桌面端和移动端记录间分割线，改用与宿主表格一致的交替背景色；选中和悬停颜色使用官方主题变量
- 桌面单元格上下间距从 23px 缩减为 8px，行高跟随宿主表格变量（默认 60px）；控件尺寸不变，内容需要时可撑高
- 移动端卡片和字段间距同步收紧，保持自动高度
- 保留按关联记录 `created_at` 默认倒序、旧记录未知时间稳定置后，以及搜索、分页、批量删除行为
- 周期判定、提前重置及结果未知时不自动重试的保护保持不变

## 兼容与升级

- SDK 与打包工具继续固定官方 CPR v3.33.0，提交 `8c8618aa0f841638262262e3338c115bc075f125`
- 要求官方 Codex Proxy RS **≥3.33.0**，支持 RPC v7、Management v2、Maintenance v1，不设置宿主版本上限；无上限不代表已验证所有未来版本
- 插件标识为 `tumi.key-reset-follow`，作者为 `tumi`；从 v0.1.9 更新保持相同标识与私有状态 schema，升级后仍须核对原有关联、开关、暂停状态和结果未知保护
- 从 `ming321.key-reset-follow` 切换属于独立安装：先停用旧插件，避免两个插件处理同一批密钥；旧实例状态不会自动迁移，新关联只建立基线、不补做历史清零
- Linux x86_64 与 ARM64 安装包及对应 SHA-256 文件由标签工作流生成

本地验证覆盖前端 lint、全部 15 项前端测试、类型检查与生产构建，以及版本、清单兼容声明和差异空白检查。

上一版本 v0.1.9 的双架构 CI 已通过 Rust 格式检查、Clippy、测试、构建及打包；这不替代本次 v0.2.0 标签的独立验证。

浏览器交互检查与截图受到环境限制，未完成。真实宿主安装、升级和状态保留尚未重新联调；前端检查与 CI 不能替代该验证。本次发布不执行生产部署。
