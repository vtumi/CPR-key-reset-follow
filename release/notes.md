# v0.2.4

## 更新

- 操作区域参照父项目 CPR v3.41.2 的 ZTable，桌面表格的操作表头和按钮列固定在右侧，横向滚动时保持可见。
- 右侧仍有隐藏内容时显示左侧阴影，滚到末尾后移除；保留行背景、选中状态和窄屏卡片布局。
- 启用、禁用、删除、批量操作及账号重置激活行为不变。

## 兼容与升级

- 要求官方 CPR **≥3.41.2**，不设置版本上限；SDK 与打包工具继续固定 `ba3baddbda7293d1d76ea066dd5e42298618c15a`。无上限不表示已验证未来版本。
- 保持 `tumi.key-reset-follow` 插件标识与私有状态 schema，在原实例更新，不要卸载重装。关联、暂停状态、周期基线与未知结果保护保留。
- 延续 v0.2.3 的提前重置自动跟随和按账号去重激活。连接测试会产生真实上游请求并可能消耗账号额度。

## 验证

本地通过 Rust 1.99.1 格式检查、严格 Clippy、35 项测试，以及前端 lint、10 项业务测试、类型检查与生产构建。前端使用 Node 24.22.1、现有 pnpm 11.25.0；标签工作流使用仓库指定的 pnpm 12.6.0 独立检查。

按要求不进行界面细节测试。真实宿主安装与升级状态保留未重新联调；单元测试、构建和 CI 不能替代该验证。本次发布不执行生产部署。

Linux x86_64、ARM64 安装包及 SHA-256 校验文件通过手动标签工作流构建并上传，产物以该次 CI 实际结果为准。
