# v0.1.8

## 更新

- 列表参照宿主 API 密钥页面，新增按密钥名称及账号名称、邮箱、ID 的搜索，忽略大小写和首尾空白
- 密钥名称、账号、重置时间和状态支持升序、降序与默认排序；窄屏使用排序选择框
- 状态字段移到账号字段后，移除左上角统计，底部增加筛选结果总数、每页条数和分页栏，默认每页 20 条
- 搜索、排序和每页条数变更回到第一页；删除或刷新导致页数减少时自动回到有效页，空结果显示独立提示
- 列表底部仅显示筛选结果的“共 … 条”，不再附加匹配提示；行内启用/禁用文案简化，删除确认以空格分隔密钥名称、不添加引号
- 移除“添加关联”左侧的刷新按钮，保留列表自动更新及错误重试
- 排序与分页只影响列表展示，不改变周期判定、提前重置设置或结果未知时不重试的保护

## 兼容与升级

- SDK 与打包工具继续固定官方 CPR v3.33.0，提交 `8c8618aa0f841638262262e3338c115bc075f125`
- 要求官方 Codex Proxy RS **≥3.33.0**，支持 RPC v7、Management v2、Maintenance v1，不设置宿主版本上限；无上限不代表已验证所有未来版本
- 插件标识为 `tumi.key-reset-follow`，作者为 `tumi`；从 v0.1.7 更新保持相同标识与私有状态 schema，升级后仍须核对原有关联、开关、暂停状态和结果未知保护
- 从 `ming321.key-reset-follow` 切换属于独立安装：先停用旧插件，避免两个插件处理同一批密钥；旧实例状态不会自动迁移，新关联只建立基线、不补做历史清零
- Linux x86_64 与 ARM64 安装包及对应 SHA-256 文件由标签工作流生成
